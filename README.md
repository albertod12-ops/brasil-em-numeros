Brasil em Números — Brazil's national statistics as a one-page yearbook: population, economy, prices, work and states, 2019–2024, with a year explorer that follows the whole page and real figures with their sources. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a year (2019–2024) and the KPI strip, focus line and charts follow it; the states table sorts by column; the layout works on a phone.
